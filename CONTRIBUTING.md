# Contributing to Spar Nord ATM ETL Project

Thank you for your interest in contributing to this data engineering project!

## How to Contribute

### Reporting Issues
- Describe issues clearly with stack traces
- Include Spark job logs if relevant
- Specify data volumes and system configuration

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Install dependencies: `pip install -r requirements.txt`
4. Test with sample data
5. Make your improvements
6. Push and submit a Pull Request

## Code Guidelines

- Follow PEP 8 conventions
- Document ETL transformations
- Include data quality checks
- Optimize for performance

## Areas for Contribution

- Improving ETL efficiency
- Enhanced data validation
- Better error handling
- Performance optimization
- Documentation improvements
- New data sources

## Pull Request Process

1. Test with sample datasets
2. Include performance metrics
3. Document changes clearly
4. Update README if needed

Thank you for contributing! 🙏
